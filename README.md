A short text written to relax the reader. It shows a slow night scene — a river under the stars, an empty field, a full sky — rather than telling anyone to relax: the lines shorten as the text goes on, so the reading itself slows down, and the last line leaves a thought that keeps growing after it ends. `main.ts` (Node 22, standard library only) writes the text to `/output/entry.txt`; the program is deterministic, with no randomness, clock, or network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
